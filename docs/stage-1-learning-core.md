# 阶段 1.5：学习核心真实化

## 本阶段目标

把 C0 原型里的学习页核心能力落到真实前后端：

- 任务库：按今天 / 本周 / 已完成查看。
- 目标：名称、描述、目标值、截止日期可新建和编辑。
- 番茄钟：专注 / 短休息 / 长休息，时长可自定义。
- 时间记录：专注结束自动写入后端，按天查看和删除。
- 学习板块不再出现「科目」入口。

## 已完成

### 后端

- 新增 `learning_time_sessions` 表，迁移 `e90bab7578b7`。
- 新增接口：
  - `GET /api/learning/tasks?from_date=&to_date=`
  - `GET /api/learning/time-sessions?date=`
  - `POST /api/learning/time-sessions`
  - `DELETE /api/learning/time-sessions/{id}`
- 新增测试 `tests/test_learning_time.py`。

### 前端

- 今日页加入番茄钟：
  - 专注 / 短休息 / 长休息切换。
  - 开始、暂停、重置。
  - 设置面板自定义三个时长（1–180 分钟）。
  - 选择今天待办任务，或自由学习。
  - 专注结束自动写一条时间记录。
  - 今日专注列表与合计。
- 新增任务页 `/tasks`，按今天 / 本周 / 已完成分组。
- 目标页支持新建和编辑名称、描述、目标值、单位、截止日期。
- 导航从「今日 / 目标 / 科目 / 代买」改为「今日 / 目标 / 任务 / 代买」。
- 今日页添加任务不再选科目，任务行不再显示科目。
