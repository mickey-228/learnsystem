# 个人生活面板 · 产品需求文档

> 版本：v0.2（已确认初版）
> 日期：2026-11-09
> 状态：需求已确认，待做视觉原型
> 范围：单人使用、本地优先；学习、待买、资金项目、健康、财务、习惯、日程、复盘
> 原型：单文件静态 HTML，中文假数据，桌面优先，含深色模式

## 1. 产品定位

把现在只有学习功能的系统，扩展成**个人生活面板**：

```text
学习：今天学了什么、投入多少、离目标多远
待买：想买什么、本月花了多少、有没有超预算
资金：存钱去旅游、买大件等资金项目进度
健康：睡眠、运动、饮水、体重、心情、生理期
财务：本月收入、支出、分类占比
习惯：每天要做的固定动作和连续天数
日程：今天、本周的安排
```

目标不是做「功能大全」，而是用一套低摩擦的记录，把生活里重要的部分量化出来，并在一个总览页看清全局。

## 2. 用户与场景

- 单人使用，不注册、不共享、不做权限。
- Windows 桌面浏览器优先，手机端后续适配。
- 希望记录成本低，不想被复杂工具拖住。
- 数据本地保存，可导出、可备份。

| 时间 | 场景 | 期望 |
|---|---|---|
| 早上 | 打开总览 | 1 分钟看清学习、待买、健康、习惯、日程 |
| 白天 | 学完、想买东西、运动 | 随手记录，不超过 3 次点击 |
| 晚上 | 睡前 | 补记睡眠、饮水、心情、生理期 |
| 周末 | 复盘 | 看本周趋势、预算、健康、习惯完成度 |

## 3. 信息架构与导航

主入口固定 **5 个**，设置放右上角：

```text
1. 总览        /overview     展示所有领域的今日状态
2. 学习        /learning     今日计划、目标、任务、笔记、时间记录、统计
3. 生活        /life         待买、资金项目、财务、习惯、日程
4. 健康        /health       今日记录、趋势、目标
5. 复盘        /review       周汇总、跨域指标、导出
```

「生活」是二级分组，内部用标签切换：

```text
生活
├─ 待买        /life/shopping
├─ 资金项目    /life/funds
├─ 财务        /life/finance
├─ 习惯        /life/habits
└─ 日程        /life/schedule
```

学习下的「目标」「任务」「笔记」也收进二级页面，不再占主导航。

## 4. 量化指标

### 4.1 总览

| 指标 | 公式 |
|---|---|
| 每日记录完整度 | 学习、待买/资金、健康、财务、习惯、日程共 6 项，当天有记录各得 1 分，满分 6 |
| 连续记录天数 | 连续多少天完整度 ≥ 1 |
| 本周完成度 | 本周有记录的天数 / 7 |

### 4.2 学习

| 指标 | 公式 |
|---|---|
| 今日完成率 | 今日完成任务数 / 今日任务数 |
| 每个目标今日完成率 | 该目标下今日完成任务数 / 该目标下今日任务数 |
| 今日学习时长 | 今日完成任务实际分钟数之和 |
| 连续打卡天数 | 从今天往前连续有打卡记录的天数 |
| 目标剩余量 | 目标值 − 累计打卡量；非量化目标用里程碑完成数 |
| 本周学习时长 | 本周打卡分钟数之和 |
| 今日专注时长 | 今日完成的番茄专注会话分钟数之和 |
| 今日番茄数 | 今日完成的专注会话数 |
| 本周专注时长 | 本周专注会话分钟数之和 |
| 笔记总数 | 已连接 Obsidian vault 中可索引的 Markdown 笔记数 |
| 最近同步 | 最后一次成功扫描 vault 的时间 |

### 4.3 待买与资金项目

| 指标 | 公式 |
|---|---|
| 本月预算 | 当月预算金额 |
| 本月已支出 | 状态为「已买」的实际金额之和 |
| 本月剩余 | 预算 − 已支出；未花完可结转到下月 |
| 预算使用率 | 已支出 / 预算 |
| 待买预估 | 状态为「想买」的预估金额之和 |
| 超支额 | max(已支出 − 预算, 0) |
| 资金项目进度 | 已投入金额 / 目标金额 |
| 资金项目月供 | 距离截止日期所需每月投入 |

### 4.4 健康

| 指标 | 公式 |
|---|---|
| 睡眠时长 | 起床时间 − 入睡时间，跨午夜自动处理；也可手动填写 |
| 7 日平均睡眠 | 最近 7 天睡眠时长平均值 |
| 本周运动分钟 | 本周所有运动记录分钟数之和 |
| 饮水达标天数 | 最近 7 天饮水 ≥ 目标的天数 |
| 体重变化 | 最近一次体重 − 30 天前体重 |
| 心情均值 | 最近 7 天心情评分平均值 |
| 生理期周期 | 两次经期开始日期间隔；预测下次日期（P2） |

### 4.5 财务、习惯、日程

| 指标 | 公式 |
|---|---|
| 本月结余 | 本月收入 − 本月支出 |
| 分类支出占比 | 某分类支出 / 本月总支出 |
| 习惯连续天数 | 从今天往前连续打卡天数 |
| 习惯本周完成率 | 本周打卡次数 / 计划次数 |
| 今日日程数 | 今天未完成日程数 |
| 本周日程完成率 | 已完成日程 / 本周日程 |

## 5. 功能需求

### 5.1 总览（P0）

**目的**：一个页面展示所有领域的今日状态。

**页面元素**：

- 顶部：日期、星期、连续记录天数、深色模式开关。
- 六个领域卡片：学习、待买、健康、财务、习惯、日程。
- 每个卡片显示 1–3 个关键数字和一句状态描述，点击进入对应模块。
- 今日时间线：学习打卡、待买已买、健康记录、习惯打卡、日程事件。
- 快速操作：加学习任务、加待买、记录健康、记一笔支出、打卡习惯。
- 每日完整度：6 个圆点或进度条。

**规则**：

- 没有数据的领域显示引导，不显示误导性的 0。
- 卡片数字与各模块明细一致。
- 写操作成功后刷新总览。

### 5.2 学习（P0，已有功能 + 统计）

**已有**：目标、今日计划、打卡、完成/重开、完成率、实际时长。科目作为内部标签保留，不在学习页单独展示。

**本期增加**：

- 学习页顶部：今日完成率、今日学习时长、连续打卡天数、本周学习时长、今日专注分钟。
- 按今日每个目标的完成率展示；没有关联目标的任务归入「未分类」。
- 目标支持量化目标和非量化目标（例如「读完一本书」用里程碑）。
- 目标名称由用户自定义，不预设固定名称；卡片用短名称（如「雅思」「算法」），长描述放在正文。
- 目标/任务/笔记收进学习二级页面。
- 验证式打卡和五问复盘：按工程量放到 P1，不在首版强制。

**规则**：

- 完成任务生成打卡；重开撤销对应打卡。
- 非量化目标用里程碑完成数计算进度。
- 今日完成率只统计当天任务。
- 番茄钟记录「专注时间」，打卡记录「任务完成结果」，两者独立统计，不互相替代。

#### 5.2.1 番茄钟与时间记录（P0）

**目的**：把「学了多久」从手动填写变成可记录、可回看的专注会话。

**功能**：

- 番茄钟模式：默认专注 25 / 短休息 5 / 长休息 15；可在设置面板自定义三个时长（1–180 分钟），保存后重置当前计时。
- 开始、暂停、重置；倒计时结束有提示音或页面提示。
- 一次专注结束后自动生成一条时间记录，关联任务、目标。
- 支持手动补记：开始时间、结束时间、分钟数、任务、备注。
- 今日专注记录列表：时间、任务、分钟数；今日合计、本周合计。
- 统计：今日番茄数、今日专注分钟、本周专注分钟、按任务分布。
- 学习页顶部显示「今日专注」卡片；总览页学习卡片同步显示。

**规则**：

- 番茄钟在前端计时，结束时调用后端写一条 `learning_time_sessions`。
- 休息不计入学习时长。
- 手动补记与番茄记录同样计入统计。
- 同一时间段不允许重复记录（P1）。
- 首版刷新页面不恢复进行中的计时；已完成的会话不丢。P1 用 localStorage 恢复。
- 自定义的三个时长首版保存在当前会话；P1 持久化到本地设置。
- 计时器暂停时不计时；页面切走但未暂停时继续计时（前端实现需明确）。

#### 5.2.2 Obsidian 笔记（P0）

**目的**：学习时直接看到 Obsidian 里的相关笔记，并能一键回到 Obsidian 编辑。

**功能**：

- 连接设置：vault 名称、本地路径、同步方式（文件夹扫描 / Local REST API）。
- 笔记列表：标题、路径、标签、更新时间；按任务/标签筛选。
- 打开笔记：使用 `obsidian://open?vault=<vault>&file=<path>` 唤起 Obsidian。
- 同步：后端扫描 vault 内的 Markdown，建立索引；显示最近同步时间、笔记总数。
- 关联：笔记可以关联任务/目标；学习任务可以引用笔记。
- 统计：笔记总数、本周新增/修改笔记数、最近同步时间。

**集成方式**：

1. **后端扫描本地 vault（推荐，首版）**：配置 vault 路径后，后端读取 `.md` 文件，解析标题、标签（frontmatter/`#tag`）和修改时间，建立只读索引。
2. **Obsidian Local REST API 插件（P1）**：适合需要实时同步和写入的场景；需要用户安装并开启插件。
3. **Obsidian URI（首版用于打开）**：只负责唤起 Obsidian 打开指定笔记，不读取内容。

**约束**：

- 浏览器不能直接读取本地文件；必须由本地后端扫描，或用户手动导入。
- vault 路径只保存在本地设置，不上传服务器。
- 首版只读，不在应用里编辑 Obsidian 笔记；写入放 P1。
- 扫描要跳过 `.obsidian/`、附件和隐藏目录，只索引 Markdown。

### 5.3 待买（P0）

**目的**：把想买的东西先记下来，按月控制预算。

**状态**：想买 / 已买 / 放弃。不再有「代买对象」和「待收款」。

**字段**：

| 字段 | 必填 | 说明 |
|---|---|---|
| name | 是 | 物品名称 |
| category | 否 | 自定义分类，默认「其他」 |
| quantity | 是 | 默认 1 |
| estimated_price | 否 | 单件预估价格 |
| actual_price | 否 | 标记已买时必填 |
| priority | 是 | 自定义优先级，预置「必需 / 想要 / 观望」 |
| status | 是 | 想买 / 已买 / 放弃 |
| channel | 否 | 购买渠道，选填 |
| reason | 否 | 为什么想买 |
| cooling_until | 否 | 冷静期截止日；未到期时显示提醒 |
| url | 否 | 商品链接 |
| note | 否 | 备注 |
| bought_at | 否 | 购买日期 |

**预算**：

- 月度总预算。
- 支持按分类设置子预算（P1）。
- 未花完的预算可结转到下个月（可开关）。
- 支持为「存钱去旅游」这类目标建立资金项目，见 5.4。

**页面元素**：

- 月份切换、预算卡片、使用率进度条、超支提示。
- 汇总：待买件数、待买预估、本月已买件数、本月已支出。
- 快速添加：名称、分类、数量、预估单价、优先级。
- 列表：按状态、分类、优先级筛选；名称搜索。
- 条目操作：编辑、标记已买、放弃、删除。
- 标记已买时弹窗填写实际价格，未填不允许提交。

**规则**：

- 删除为硬删除，不做撤销/回收站。
- 标记已买时实际价格必填。
- 预算未设置时，剩余和使用率显示「—」。
- 月份之间数据隔离；删除预算不删条目。
- 冷静期未到的条目在列表中显示提醒。

### 5.4 资金项目（P0）

**目的**：记录「投入资金的项目」，例如存钱去旅游、买大件、学习基金。

**字段**：

| 字段 | 说明 |
|---|---|
| name | 项目名称，例如「去日本旅游」 |
| target_amount | 目标金额 |
| saved_amount | 已投入金额 |
| deadline | 目标日期 |
| monthly_plan | 每月计划投入，可自动计算 |
| category | 旅游 / 大件 / 学习 / 应急 / 其他 |
| status | 进行中 / 已完成 / 暂停 |
| note | 备注 |

**页面元素**：

- 项目卡片：目标、已存、进度条、剩余、距离截止日期。
- 投入记录：日期、金额、备注。
- 项目汇总：总目标、总已存、本月计划投入。
- 项目可关联一笔支出（例如旅游回来后记实际花费）。

**规则**：

- 已存金额不能为负；投入记录可删除。
- 进度 = 已存 / 目标；目标为 0 时显示「—」。
- 月供建议 = 剩余金额 / 剩余月份，向上取整。

### 5.5 健康（P0）

**目的**：每天记录多条健康事件，形成趋势；支持生理期、用药和症状。

**记录方式**：一天可以有多条记录，按类型区分。

| 类型 | 字段 |
|---|---|
| 睡眠 | 入睡时间、起床时间、时长（自动算，可手填）、质量 1–5 |
| 运动 | 类型、时长、强度、备注；一天可多条 |
| 饮水 | 毫升；一天可多次累加 |
| 体重 | kg |
| 心情 | 1–5 |
| 精力 | 1–5 |
| 生理期 | 开始/结束日期、流量、症状、备注 |
| 用药 | 名称、剂量、时间、备注 |
| 症状 | 名称、严重程度、备注 |

**页面元素**：

- 今日摘要：睡眠、运动、饮水、体重、心情。
- 快速记录：选择类型后填最少字段即可保存。
- 今日时间线：按时间展示多条记录。
- 趋势：7/30 天睡眠、运动、饮水、体重、心情。
- 目标：自定义目标（例如睡眠 ≥ 7 小时、每周运动 ≥ 150 分钟、饮水 ≥ 2000ml）；体重目标不做。
- 生理期：日历标记、周期长度、症状统计；预测下次日期放 P2。

**规则**：

- 睡眠同时支持「起止时间」和「直接填时长」，两者都保存；冲突时以手动时长为准。
- 饮水多条记录自动累加为当日总量。
- 运动一天可多条，按类型汇总。
- 空字段不计入平均值。
- 生理期记录不参与普通健康均值。
- 健康数据本地保存；P1 增加本地加密和导出提醒。

### 5.6 财务（P1）

**目的**：轻量记录本月收入、支出和分类占比，不做复式记账。

**字段**：日期、类型（收入/支出）、金额、分类、账户（可选）、备注、关联待买/资金项目（可选）。

**页面元素**：

- 本月收入、支出、结余。
- 分类支出占比。
- 最近交易列表。
- 快速记一笔。

**规则**：

- 金额必须大于 0。
- 删除交易为硬删除。
- 与待买/资金项目的关联只做展示，不自动生成交易。

### 5.7 习惯（P1）

**字段**：名称、图标/颜色、频率（每天/每周 N 次）、目标次数、开始日期、归档状态。

**页面元素**：

- 今日习惯清单，点击打卡。
- 连续天数、本周完成率。
- 习惯历史日历。

**规则**：

- 每天每个习惯最多一次打卡；重复点击取消。
- 归档习惯保留历史，不再出现在今日清单。

### 5.8 日程（P1）

**字段**：标题、日期、开始/结束时间、地点、类型、备注、完成状态。

**页面元素**：

- 今日/本周视图。
- 快速添加。
- 完成/取消完成。

**规则**：

- 结束时间必须晚于开始时间。
- 过期未完成事件标记为「已过期」。

### 5.9 复盘（P1）

- 周切换。
- 学习、待买/资金、健康、财务、习惯、日程六块摘要。
- 每日记录完整度热力格（7 天 × 6 域）。
- 文字复盘：做得好、没做好、下周调整。
- 导出 Markdown / CSV。

### 5.10 设置（P1）

- 时区、周起始日。
- 货币、体重单位、饮水单位。
- 主题：浅色 / 深色 / 跟随系统。
- 预算结转开关。
- 数据导出/导入 JSON。
- 修改登录密码（阶段 2 后）。
- 清空某个月或某个域的数据（二次确认）。

## 7. 数据模型

### 7.1 学习（已有 + 时间记录）

- `learning_goals`、`learning_subjects`、`learning_day_plans`、`learning_plan_items`、`learning_checkins`。
- `learning_time_sessions`：subject_id、goal_id、plan_item_id、started_at、ended_at、minutes、mode(`focus`/`short_break`/`long_break`)、source(`pomodoro`/`manual`)、note、created_at。
- `knowledge_vaults`：name、path、sync_mode(`folder`/`rest_api`)、last_synced_at、enabled。
- `knowledge_notes`：vault_id、path、title、tags_json、modified_at、linked_subject_id、linked_goal_id、indexed_at。

> 学习页不再展示「科目」标签；`learning_subjects` 作为内部标签保留，任务按今天 / 本周 / 已完成分组展示。
> 目标名称由用户输入：`learning_goals.title` 存短名称，`description` 存长描述。

### 7.2 待买与资金

- `life_monthly_budgets`：month(unique)、amount、rollover_enabled、note。
- `life_shopping_items`：name、category、quantity、estimated_price、actual_price、priority、status、channel、reason、cooling_until、url、note、bought_at。
- `life_categories`：name、color、sort_order。
- `life_fund_projects`：name、target_amount、saved_amount、deadline、monthly_plan、category、status、note。
- `life_fund_entries`：project_id、date、amount、note。

> 现有 `life_proxy_purchases` 需要迁移为 `life_shopping_items`，删除 `payee`，增加分类、优先级、渠道、冷静期、实际价格等字段。

### 7.3 健康

- `health_records`：date、type、start_at、end_at、minutes、value、unit、quality、note、metadata_json。
- `health_periods`（P1）：start_date、end_date、flow、symptoms、note。
- `health_goals`：type、target_value、unit、period、active。

### 7.4 财务、习惯、日程

- `finance_transactions`：date、type、amount、category、account、note、linked_type、linked_id。
- `finance_categories`：name、type、color。
- `habits`：name、color、frequency、target_count、start_date、archived。
- `habit_checkins`：habit_id、date(unique with habit_id)。
- `schedule_events`：title、date、start_time、end_time、location、type、note、done。

### 7.5 共享

- `app_settings`：key、value（时区、周起始日、货币、主题、预算结转等）。

## 9. 外部集成研究

### 9.1 小米健康手表

结论：**首版不能直接读取**。小米手环/手表数据主要在小米健康/小米运动健康 App 内，没有面向个人开发者的公开 Web API；网页也无法直接通过蓝牙读取手表。

可行路径：

1. **手动记录**（首版默认）：睡眠、运动、体重手动填。
2. **导出导入**（P1）：如果 App 支持导出 CSV/JSON，做一个导入器。
3. **Android 桥接**（P2）：通过 Health Connect 或 Gadgetbridge 读取，再由手机端同步到后端。
4. **第三方服务**（P2）：如果以后有开放 API，再做适配。

### 9.2 价格历史 / 降价提醒

需求存在，但首版不接。实现前先在 GitHub 调研可接入的开源项目，候选方向：

- 通用网页变更监控：changedetection.io、Huginn。
- 电商价格跟踪：搜索 `price tracker`、`price history` 相关项目，确认是否支持国内电商。
- 自建方案：定时抓取商品链接，记录价格变化，达到阈值提醒。

约束：抓取可能违反站点条款，且国内电商反爬严格；首版只做「手动记录价格」，自动抓取放 P2。
