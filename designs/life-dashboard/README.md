# 小生活 · 总览页视觉方向

这是「个人生活面板」总览页的第一版视觉探索，包含三个温暖方向和一个深色预览。

## 打开方式

在项目根目录启动静态服务：

```powershell
& 'E:\learnsystem\backend\.venv\Scripts\python.exe' -m http.server 4311 --directory 'E:\learnsystem\designs'
```

然后打开：

```text
http://127.0.0.1:4311/life-dashboard/Overview%20Comparisons.html
```

画布操作：滚轮缩放、拖拽平移；点击画板标签或右上角展开图标可全屏查看。

## 三个方向

| 方向 | 气质 | 关键手法 |
|---|---|---|
| A · 奶油手账 | 温和、纸张感、像一本个人年鉴 | 暖纸底色、宋体标题、陶土色主色、和纸胶带、微不规则圆角 |
| B · 森系小屋 | 自然、松弛、轻微植物感 | 鼠尾草绿、圆润卡片、叶片点缀、胶囊导航、柔和阴影 |
| C · 糖果贴纸 | 活泼、贴纸感、略带玩具气 | 黑描边卡片、彩色偏移阴影、贴纸式导航、轻微旋转 |

### C 方向细化

在 C 的基础上又做了三版，布局不变，只比较视觉语言：

| 版本 | 气质 | 关键手法 |
|---|---|---|
| C0 · 糖果贴纸（原版） | 活泼、贴纸感 | 多色淡底卡片、黑描边、彩色偏移阴影、彩虹周柱与完整度圆点 |
| C1 · 果冻贴纸 | 更软、更轻、更甜 | 去掉黑描边、大圆角、柔和彩色投影、果冻色块 |
| C2 · 手绘贴纸 | 更像手账和涂鸦 | 虚线边框、波浪下划线、和纸胶带、手写标题 |
| C3 · 复古糖果 | 更厚、更 70s | 粗黑边框、大偏移阴影、棋盘格顶条、奶油黄主色 |

单独查看 C 变体（打开就是四版并排，不用再找章节）：

```text
http://127.0.0.1:4311/life-dashboard/C%20Variants.html
```

## C0 完整原型

C0 已扩展成完整的多页面原型：

- 多文件版：`C0 Prototype.html` + `c0-app.jsx`
- 单文件版：`C0 Prototype (Standalone).html`
- 预览地址：
  - http://127.0.0.1:4311/life-dashboard/C0%20Prototype.html
  - http://127.0.0.1:4311/life-dashboard/C0%20Prototype%20%28Standalone%29.html

覆盖页面：

- 总览：六域卡片、今日时间线、快速记录、本周节奏
- 学习：今日计划、目标、任务、笔记；目标名称可自定义（新建/编辑），任务库按今天 / 本周 / 已完成分组，含可自定义时长的番茄钟、时间记录和 Obsidian 笔记面板
- 生活：待买、资金项目、财务、习惯、日程
- 健康：今日指标、快速记录、今日记录、7 日趋势、健康目标、生理期
- 复盘：六域摘要、每日完整度热力图、文字复盘、导出按钮
- 交互：侧栏导航、页面内标签切换、目标新建/编辑、番茄钟自定义时长/开始/暂停/重置、深色模式
- 数据：全部为静态中文假数据，不接后端

深色模式：原型侧栏底部可切换，使用暖色深底而不是纯黑。
